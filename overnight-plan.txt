ANIMATION & MOTION — APPLE-LEVEL REQUIREMENT:
The app must FEEL alive. Every interaction should have fluid, purposeful motion.
Think iOS/macOS — nothing is instant, nothing is static. Everything breathes.

IMPLEMENT THESE ANIMATIONS (add to index.css as global transitions):

Page Navigation:
- Pages fade in when navigated to (opacity 0→1, subtle translateY 8px→0, ~200ms ease-out)
- Content sections stagger in slightly (first section, then cards, then details — 50ms stagger)
- No hard cuts between pages. Ever.

Modals:
- Backdrop fades in (opacity 0→1, ~150ms)
- Modal scales up from 0.95→1.0 + fades in (opacity 0→1, ~200ms cubic-bezier(0.16, 1, 0.3, 1))
- On close: reverse — scale down + fade out (~150ms)
- This is the iOS-style spring feel. Not a linear slide. A deceleration curve.

Buttons:
- Hover: subtle brightness increase + slight scale (scale(1.02), ~150ms ease)
- Active/press: scale DOWN slightly (scale(0.97), ~100ms) — this is the Apple "press" feel
- Transition on all buttons: transition: all 0.15s cubic-bezier(0.16, 1, 0.3, 1)

Inputs:
- Focus: border color transitions smoothly to accent color (~150ms)
- Focus: subtle glow/ring fades in (box-shadow transition, not instant)
- Placeholder text fades slightly on focus

Cards:
- Hover: subtle lift effect (translateY(-1px) + slightly increased shadow, ~200ms)
- Cards in lists/grids stagger-animate on page load (each card delays 30-50ms after previous)
- Kanban card drag: smooth with subtle shadow increase while dragging

Dropdowns/Menus:
- Open: fade in + scale from 0.95→1.0, origin from the trigger element (~150ms)
- Close: fade out + scale to 0.95 (~100ms)
- Menu items have hover highlight that transitions smoothly (not instant bg swap)

Sidebar:
- Collapse/expand: smooth width transition (~250ms ease)
- Nav items: hover highlight slides in smoothly
- Active nav indicator transitions position when switching pages

Toasts/Notifications:
- Slide in from top-right + fade (translateX(100%)→0, ~300ms spring curve)
- Auto-dismiss: fade out + slide right (~200ms)

Loading States:
- Skeleton loaders with shimmer animation (subtle left→right gradient sweep)
- Spinner uses smooth rotation, not stepped
- Content fades in when loaded, replacing skeleton smoothly

Tables:
- Row hover: background color transitions smoothly (~100ms)
- Sort indicator animates rotation when sort direction changes
- New rows added animate in (fade + slideDown)

Toggle Switches:
- Smooth slide animation on the knob (~200ms spring)
- Background color transitions smoothly between on/off states

THE KEY EASING CURVE:
Use cubic-bezier(0.16, 1, 0.3, 1) for most animations — this is the Apple "spring"
deceleration feel. Fast start, gentle settle. NOT linear. NOT ease-in-out.
For quick micro-interactions (hover, press): 100-150ms
For UI transitions (modal, page, sidebar): 200-300ms
For stagger animations: 30-50ms between items
NEVER exceed 400ms — animations should feel snappy, not slow.

Add these as CSS custom properties in index.css:
--transition-fast: 100ms cubic-bezier(0.16, 1, 0.3, 1);
--transition-normal: 200ms cubic-bezier(0.16, 1, 0.3, 1);
--transition-slow: 300ms cubic-bezier(0.16, 1, 0.3, 1);
--transition-spring: 400ms cubic-bezier(0.34, 1.56, 0.64, 1);

Then USE these variables everywhere. No hardcoded transition values scattered across components.
