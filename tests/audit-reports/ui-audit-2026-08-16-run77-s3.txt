*** DISCIPLINE — 8 candidates raised, 8 killed (8x over-report) ***
================================================================================
Every one of these would have been a bad bug report. What killed each:

1. `@keyframes spin` MISSING for .address-search__spinner (index.css:3014).
   Static scan said the only spin keyframes are `icon-spin`/`appleSpinStep`,
   there is NO tailwind.config, and there are ZERO `animate-spin` usages.
   KILLED BY A BEHAVIOURAL TEST: injected the element, read its computed
   transform 250ms apart — it rotates (matrix changes, getAnimations() running).
   `@keyframes spin` is supplied by TAILWIND'S THEME (tailwindcss/theme.css,
   v4.2.2, imported via `@import "tailwindcss/theme" layer(theme)`).
   Then verified it survives PRODUCTION: `npx vite build` -> the built CSS
   contains `@keyframes spin`. Works in dev AND prod. See TICKET 2.
2. `var(--tc)` undefined x4 in .lg-storm-row__badge, inside a BORDER SHORTHAND
   — the exact Run 76 headline shape. KILLED: `.lg-storm-row*` has ZERO JSX
   consumers. Dead CSS, zero user impact. See TICKET 1.
3. `@keyframes page-fade-in` undefined for `.tab-content`. KILLED the same way:
   `.tab-content` has ZERO JSX consumers.
4. localStorage key written vs read mismatch in LeadDetail.jsx
   (`billing_dismiss_${billingModal}` written :1977 vs `billing_dismiss_measure`
   read :845 / `billing_dismiss_trace` read :907). KILLED: setBillingModal is
   only ever called with 'measure' (:848) and 'trace' (:910), so the template
   produces exactly the two literal keys that are read. Correct.
5. .auth-btn outlier on /storm-catalog (6/14px 12px vs 0/24px 13px elsewhere).
   KILLED: StormCatalog.jsx:202/215 — it is the ACTIVE PILL of a time-range
   SEGMENTED CONTROL; active (.auth-btn) and inactive (.quick-action-btn) pills
   share identical inline sizing. "Standardizing" it would make the active pill
   wider than its neighbours and break the control. Same family as the
   documented FullCalendar .fc-button-group non-bug.
6. /alerts inputs at 26px height / 0px radius / no .form-input.
   KILLED: AlertSettings.jsx:308-316 — middle segment of a numeric stepper
   whose flanking buttons carry `borderRadius: '8px 0 0 8px'` + `borderRight:
   none`. CHECK THE WRAPPER FIRST, again.
7. `.public-estimate-company` used as a className but never defined as a
   selector (while __name and __sub ARE defined). KILLED: it is a plain
   grouping div inside `.public-estimate-header` (display:flex); its two
   block-level children stack correctly with no rule needed.
8. `mini-storm-map` (Dashboard.jsx:474) and `lead-list-toolbar`
   (LeadList.jsx:373) used as classNames with no CSS rule. KILLED: both are
   semantic markers on elements fully styled by co-classes (Tailwind / .glass)
   plus inline styles. Measured correct (toolbar 110px, padding 12/24).

*** HARNESS FALSE-NEGATIVE FOUND AND WORTH KNOWING ***
Kind G scanned only client/src/*.css for @keyframes and therefore reported
`spin` as undefined when Tailwind's theme actually defines it. ANY set
difference whose "defined" side reads only app source will over-report whenever
a VENDOR stylesheet or a JS-injected <style> supplies the name. Enumerate
document.styleSheets (recursing into @layer) or grep the BUILT bundle instead.
