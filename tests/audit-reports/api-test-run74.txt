*** BUG FOUND + FIXED: 46d8480 — POST /api/estimates/:id/generate-tiers 500 ***
--------------------------------------------------------------------------------
| Endpoint | Method | Status | Result | Issue |
| /api/estimates/:id/generate-tiers | POST | 500 -> 201 | FIXED 46d8480 | null element |

estimateService.js:330  (original.line_items || []).map(item => ({ ...item,
    unit_price: Math.round((parseFloat(item.unit_price) || 0) * tier.factor*100)/100 }))
  TypeError: Cannot read properties of null (reading 'unit_price')

`|| []` guards a FALSY value only — not a truthy non-array, and not a null ELEMENT.
`{...null}` is legal and yields {}, so the spread survives; `item.unit_price` throws.
Same shape as d575bf7 / 482d4bc; same two rows as the a023c66 PDF 500.
Fix reuses the guard the estimate PDF already uses (routes/estimates.js:258):
Array.isArray() for the container + .filter(item && typeof item==='object') for elements.
