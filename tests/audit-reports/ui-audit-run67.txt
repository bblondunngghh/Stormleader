--- NEW AXIS THIS RUN: LAYOUT SHIFT ON HOVER ---
Motivated by Run 65's 5b52fb7 (a control that changed size when its state
changed, reflowing the row). That was the ACTIVE state; :hover had never
been swept. Method: for each distinct control class, measure the rect,
issue a REAL pointer hover, wait 320ms (past every transition), re-measure,
and ignore transform-only changes since those do not reflow siblings.
RESULT: 106 controls across 14 routes -> 0 layout shifts. PASS.
(3 raw hits were the sidebar auto-scrolling the hover target into view —
identical w/h/padding/font-weight before and after — tester artifact.)
